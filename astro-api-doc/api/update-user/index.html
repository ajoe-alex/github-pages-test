Update User

Updates an existing user account in the system with the provided information.

Endpoint

PUT https://api.example.com/v1/users/{userId}

Request Headers

HeaderValue
AuthorizationBearer
Content-Typeapplication/json
Acceptapplication/json

Parameters

Request Body

ParameterTypeRequiredDescription
emailstringYesUser's email address
namestringYesUser's full name
rolestringNoUser role (admin, user, viewer). Default: user

Sample Payload

json
{
  "email": "test@gmail.com",
  "name": "Test User",
  "password": "TestPassword123",
  "role": "user"
}

Responses

201 - Created

json
{
  "success": true,
  "data": {
    "user": {
      "id": "usr_345678",
      "email": "newuser@example.com",
      "name": "New User",
      "role": "user",
      "status": "pending",
      "createdAt": "2024-03-10T09:15:00Z"
    },
    "message": "User created successfully. A verification email has been sent."
  }
}

Validation Rules

  • Email must be unique and in valid format
  • Password must be at least 8 characters with mixed case and numbers
  • Name must be between 2-100 characters

Notes

  • A verification email is automatically sent to the user
  • New users start with "pending" status until email is verified
  • Rate limited to 10 requests per minute per IP
